# BLOODRUSH

Top-down twin-stick gore shooter for Android (pure Kotlin + Canvas, zero dependencies).

- **Left thumb** – move. **Right thumb** – aim and auto-fire.
- Endless waves of walkers, runners and fatties; a boss every 5th wave.
- Persistent blood layer: every hit, gib and corpse stains the floor for the rest of the run.
- Pickups: shotgun, minigun, and the boss-dropped *Blood Nova* that detonates the whole horde.
- Combos, screen shake, low-HP vignette, local high score.

## Build

Open this folder in Android Studio (Koala+) and press Run, or with a Gradle install and the Android SDK:

    gradle :app:assembleDebug   # APK: app/build/outputs/apk/debug/app-debug.apk
